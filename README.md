📋 Gestor de Planillas (Lavadero de jeans)

Sistema de escritorio desarrollado en Java y JavaFX para la interfaz grafica, orientado a la gestión y control de planillas de producción de prendas (lavado, cloro y pintura), conectado a una base de datos SQLite local.

El proyecto nace por la necesidad de un conocido de pasar las planillas de papel a digital.

## Características Principales
* **CRUD Completo:** Alta, baja, modificación y consulta de planillas en tiempo real.
* **Sincronización Automática:** La interfaz principal (TableView) se actualiza de forma instantánea ante cualquier cambio en los formularios o vistas de detalles.
* **Búsqueda Dinámica:** Localización rápida de registros mediante ID.
* **Diseño Personalizado:** Interfaz moderna con fuentes tipográficas adaptadas y estilos CSS estructurados.

## 🛠️ Tecnologías Utilizadas
* **Java** (JDK 17 o superior)
* **JavaFX** (Interfaces gráficas)
* **SQLite JDBC** (Persistencia de datos)
* **Maven** (Gestión de dependencias y empaquetado)
